# Calculator
A simple calculator application


# ⚙️ Technologies
- Python
- Tkinter

# 📔 What does it do?

Calculator App is a simple calculator that lets users perform basic mathematical operations.

It includes:

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧮 Basic calculations
- 🖥️ Simple graphical interface

# 📚 What I Learned

While building this project, I learned:

-  Creating GUIs with Tkinter
-  Handling button clicks and user interactions
-  Working with user input
-  Using Python functions to build GUI features
-  Performing mathematical operations
-  Connecting the UI with Python logic
-  Understanding classes and parent-child relationships
-  Creating and using my own objects
-  Using basic Python functions to build a graphical user interface
-  Working with themes and styling
-  Understanding basic data management
-  Organizing code into a more structured application
